# k-reel.github.io

Personal site and research blog of **Kirill Boychenko** — Senior Threat Intelligence Analyst at Socket. Covers software supply chain threats, malware analysis, adversary tradecraft, and detection engineering across ecosystems including npm, PyPI, Go, RubyGems, NuGet, Crates, and browser/developer extensions.

**Live site:** [https://k-reel.github.io](https://k-reel.github.io)

## Sections

- [Posts](https://k-reel.github.io/) — research write-ups on supply chain attacks, malware campaigns, and ecosystem abuse
- [Publications](https://k-reel.github.io/publications/) — external articles, reports, and contributions
- [Presentations](https://k-reel.github.io/presentations/) — talks and conference appearances
- [Categories](https://k-reel.github.io/categories/) · [Tags](https://k-reel.github.io/tags/) · [Archives](https://k-reel.github.io/archives/)
- [About](https://k-reel.github.io/about/)

## Tech stack

Jekyll with the [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) theme. Built and deployed via GitHub Actions on push to `main`.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Then visit `http://localhost:4000`.
